3. DESCRIPTION OF AI USE
------------------------------------------------------------
Briefly describe what you used AI for and how:

I used Claude throughout this assignment, and it wrote most of
the Dart code in app/lib after I described what each part had
to do.

Specifically I used it for:

- Reading the assignment PDF and the API reference with me, and
  making a checklist of the ten requirements.

- Checking the live API before writing the client, so the code
  matched the real responses. This is how I found that the
  scores are large negative numbers and that some rows have
  invalid coordinates.

- Writing the API client, the SQLite database code, the
  repository, the WorkManager background sync, and the four
  screens.

- Explaining concepts I did not know before this assignment:
  how WorkManager runs in a separate isolate, why the visit has
  to be polled instead of returning a distance, and why the
  image upload needs multipart/form-data instead of JSON.

- Debugging build errors. The Gradle build failed with
  "Could not close incremental caches" because my project is on
  E: and the Flutter packages are on C:. It also helped me find
  that I had accidentally created two Flutter projects inside
  each other, so the wrong app was running.

- Writing README.txt and this declaration.

I did not use AI to build or modify the backend. The backend is
the one provided by the faculty and I only send requests to it.
I did not copy a complete solution from anyone.
